# DataLens
Client-side CSV explorer with RFC-style quoting support, header selection, top frequencies, summaries, numeric sums/averages and a frequency chart.

CSV files remain in the browser; maximum file size 3MB. This is an exploratory utility and not an ETL service.

Demo after Pages activation: https://santdevfull.github.io/datalens/
Run python -m http.server 8080; tests npm test (Node 22+). MIT license.
