# InvoiceKit
Invoice and quote generator with line items, quantities, integer-cent math, configurable tax rate and browser print/PDF flow.

Print to PDF using the built-in browser print dialog. This is a local educational app, not an electronic tax invoice issuer.

Demo: https://santdevfull.github.io/invoicekit/ after Pages. Run: python -m http.server 8080. Test: npm test. MIT license.
