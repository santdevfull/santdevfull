# StudyLoop
Spaced-repetition flashcard app with review queue, reveal/retry, interval scheduling and browser persistence.

Simplified scheduling model: intervals 1 day, 3 days, then x2.3 growth (up to 365 days). This is an educational scheduler, not an official SM-2 implementation.

Demo after Pages deploy: https://santdevfull.github.io/studyloop/
Local server: python -m http.server 8080. Tests: npm test (Node 22+). MIT license.
