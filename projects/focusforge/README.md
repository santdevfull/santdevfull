# FocusForge
Pomodoro timer with adjustable work duration, 5-minute breaks, pause/reset and local session counters.

Live demo (after Pages activation): https://santdevfull.github.io/focusforge/

Run: python -m http.server 8080 (open http://localhost:8080).
Test: npm test (Node 22+). Native browser APIs, no tracking. MIT license.
