# SprintBoard
Responsive agile task board. Move tasks through To do, In progress and Done; priority and completion analytics; local-first persistence.

Demo after GitHub Pages deploy: https://santdevfull.github.io/sprintboard/
Run python -m http.server 8080 and open http://localhost:8080. Tests via npm test (Node 22+).

Design: functional state transitions, input validation, safe rendering using textContent, and GitHub Actions CI/CD. MIT license.
